# Gait Tester

スマホで撮った歩行動画（左側面・右側面・前方・後方の最大4本）から、AI（MediaPipe Pose）で関節の動きを推定して歩行を解析するWebアプリです。動画は端末の外に送信されません。

## できること
- 動画の選択・カメラ撮影・画面内録画、解析範囲の指定、1コマ送り・再生（×0.25〜×1、骨格を重ねて表示）
- 側面：初期接地・頭部最高点・足尖離地の体幹・股・膝・足関節角度、歩行周期8相の区切りと相ごとの問題レポート
- 前方・後方：立脚中期の骨盤の傾き・体幹側屈・膝の見かけの外反内反（FPPA）
- **時間・距離因子**：歩行速度・歩行率（ケイデンス）・ストライド長・左右の歩幅・立脚／遊脚時間・左右比
  - 距離は「距離の基準を設定」で動画上の2点（例：床のテープ2 m）をタップして換算。基準がないときは対象者の身長から推定
- **1歩行周期の平均波形**（0〜100%にそろえた平均±SD、左右の重ね描き）
- 異常値・異常パターン候補・左右差の自動抽出（判定幅と文献はアプリ内「参考数値」に記載）
- **対象者・検査情報**、**印刷・PDF保存用レポート**（代表場面の画像つき）、総合CSV・フレームCSV
- **解析データの保存・読み込み（.json）** と端末内への自動保存（再読み込みしても復元できる）
- PC版AI（RTMPose）の結果（`gaittester-keypoints-v1` 形式のJSON）の読み込み
- ホーム画面に追加して使える（PWA）。「オフライン用にAIを保存」でネットなしでも解析できる

### 手動デジタイズ版（`manual.html`）
AIが使えないとき・AIの値を確かめたいときに、動画を止めて関節の位置を自分でタップして計測します。AI版と同じ角度の定義・判定幅を使います。
- 場面（初期接地・立脚中期・足尖離地／右・左立脚中期）を選び、側面は6点（肩・股関節・膝・足首・踵・つま先）、前方・後方は8点（左右の肩・股関節・膝・足首）をタップ
- 指を置くと拡大鏡が出て、指を離した位置に点が決まる。点の名前をタップしてからドラッグすると、指の動いた分だけ点が動く（細かい修正用）
- 記録した場面ごとの角度と画像、平均±SD、判定、左右比較、異常パターンの候補
- 初期接地を2回続けて記録すると周期時間・歩行率、距離の基準があれば歩行速度・ストライド長
- 対象者情報、印刷・PDF用レポート、CSV、計測データの保存・読み込み（.json）と自動保存

## オフライン版（1ファイル）
`offline/` の2つのHTMLは、ダブルクリックで開くだけで使えます（サーバー・ネット不要）。2つを同じフォルダに置くと、互いのリンクで行き来できます。
| ファイル | 内容 |
| --- | --- |
| `offline/GaitTester_offline.html` | AI版（約16 MB）。AI（MediaPipe・標準モデル）とデモを内蔵 |
| `offline/GaitTester_manual_offline.html` | 手動デジタイズ版（約1 MB）。デモ動画つき |

- 「デモを見る」で、人形が歩く合成動画と解析結果をすぐに確認できます（右脚は片麻痺を想定した歩き方。実際の患者のデータではありません）
- 内蔵のAIは「標準」モデルです。「軽量」「高精度」はネット接続時のみ使えます
- 作り直すとき：`python3 tools/build_offline.py`（MediaPipe とモデルを初回だけダウンロード。デモは `tools/make_demo.py` で作成。numpy・Pillow・ffmpeg が必要）
- 対応ブラウザ：Chrome・Edge・Safari 16.4 以降（埋め込んだデータの展開に DecompressionStream を使うため）

## ファイル
| ファイル | 内容 |
| --- | --- |
| `index.html` | アプリ本体（AI版・1ファイル） |
| `manual.html` | 手動デジタイズ版（1ファイル） |
| `sw.js` | オフライン用（アプリ本体と、読み込んだAIを保存） |
| `manifest.webmanifest`・`icon-*.png`・`apple-touch-icon.png` | ホーム画面に追加するための設定とアイコン |

`mediapipe/`（AIのライブラリとモデルを同じサーバーに置く場合）を同じフォルダに置くと、ネットにつながなくてもAIを読み込めます。

## 使い方
カメラを使うため、`https://` か `http://localhost` で開いてください（例：このフォルダで `python3 -m http.server` を実行し、`http://localhost:8000/` を開く）。

AIによる2D推定値にアプリ独自の判定幅を当てはめた参考所見です。診断には使わないでください。
