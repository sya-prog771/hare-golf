# 🧠 ゼロから作るローカルLLM

ChatGPT と同じしくみ（GPT = デコーダ型Transformer）の小さな言語モデルを、
**部品から自分で書いて・自分のPCで学習させて・オフラインで動かす** ためのフォルダです。
Hugging Face などの既製モデルやライブラリは使っていません（使うのは PyTorch の行列計算と自動微分だけ）。

> ゴルフ場アプリ本体とは無関係で、公開サイト（gh-pages）にも含まれません。

## ファイル
| ファイル | 中身 |
| --- | --- |
| `tokenizer.py` | 文字 ⇔ 番号 の変換（1文字 = 1トークン） |
| `model.py` | GPT本体。Attention・MLP・Transformerブロックを手書き |
| `train.py` | 学習（次の文字を当てる練習をくり返す） |
| `chat.py` | 学習したモデルで文章を生成（ネット不要） |
| `fetch_aozora.py` | 青空文庫から学習用の小説をダウンロード |
| `data/sample.txt` | 動作確認用の短い文章 |

## 使い方
```bash
cd local-llm
pip install torch          # GPUがあれば https://pytorch.org の手順でCUDA版を

# 1. 学習データを集める（夏目漱石・芥川・太宰・宮沢賢治など 約150万字）
python fetch_aozora.py

# 2. 学習する（まずは小さいモデルで）
python train.py --size tiny --iters 3000

# 3. 文章を書かせる
python chat.py                             # 対話モード
python chat.py --prompt "吾輩は" -n 300
```
自分の文章（日記・ブログ・メモなど）を `data/` に `.txt`（UTF-8）で置けば、それも学習に使われます。
途中から続けるときは `python train.py --resume --iters 5000`。

## 大きさの目安
| `--size` | パラメータ | かかる時間の目安 |
| --- | --- | --- |
| `tiny` | 約1M | CPUで十数分〜 |
| `small` | 約11M | CPUで数時間 / GPUで十数分 |
| `medium` | 約27M | GPU推奨 |

Mac（Apple Silicon）は自動で `mps`、NVIDIA GPU は `cuda` を使います。
`--batch` を減らすとメモリ不足を避けられます。

## 学習のようす（loss の見方）
- `学習` と `確認` の loss がどちらも下がっていれば順調
- `学習` だけ下がり `確認` が上がる → 丸暗記（過学習）。データを増やすか `--dropout 0.2` に
- 青空文庫データで `small` を学習すると、確認 loss 1.5 前後で「それっぽい文体の日本語」が出はじめます

## しくみ（ざっくり）
1. 文章を1文字ずつ番号にする（`tokenizer.py`）
2. 番号をベクトルにし、位置の情報を足す
3. **Attention**: 各文字が「前の文字のどれに注目するか」を計算して情報を集める
4. **MLP**: 集めた情報を変換する。3と4を何層も重ねる
5. 最後に「次の文字が何か」の確率を出す。正解とのズレ（loss）を小さくするよう重みを調整
6. 生成時は、確率にしたがって1文字選んでは後ろにつなげる、をくり返す

## 次のステップ
- **会話できるようにする**: 「ユーザー: …\nAI: …」形式の会話データを用意して、学習済みモデルを追加学習（ファインチューニング）する
- **トークナイザを賢く**: よく出る文字の組をまとめる BPE にすると、同じ大きさでも長い文脈を扱える
- **モデルを大きく**: 層やベクトル次元を増やす。ただし必要なデータ量と計算量も増える
