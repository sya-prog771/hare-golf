電子カルテ

院内ネットワークで使う
接続ガイド

はじめてネットワークの設定をする方向けです。上から順番にやれば、15分ほどで受付・診察室・タブレットなど何台でも同じカルテが使えるようになります。
インターネットは不要です（院内の Wi-Fi ルーターがあれば動きます）。

    まず、全体のイメージ

    院内のパソコンを1台だけ「親機（おやき）」にします。カルテのデータは親機に保存されます。
    ほかの端末（「子機」）は、ブラウザで親機のアドレスを開くだけ。子機に何かをインストールする必要はありません。

    ことばの説明（わからない言葉が出てきたら）
    親機
    カルテのデータを置くパソコン。診療中は電源を入れたままにします。
    子機
    カルテを見たり書いたりする端末。パソコン・iPad・Android タブレットなど。
    Wi-Fi ルーター
    院内の端末どうしをつなぐ箱。インターネット回線とは別の役割で、回線がなくても院内の通信はできます。
    アドレス（IPアドレス）
    院内での親機の「住所」。http://192.168.1.23:8080 のような形で、親機の黒い画面とこのページに表示されます。
    黒い画面
    親機で起動ファイルを開くと出る文字だけの画面。これが開いている間だけ、子機からカルテが使えます。

    どちらの使い方ですか？

    パソコン1台だけで使う

    ネットワークの設定はいりません。emr フォルダの中の index.html をダブルクリックするだけで使えます。

    あとから複数台に増やしたくなったら、データを引き継いで下の方法に切りかえられます。

    2台以上で同じカルテを使う

    このページの手順1〜6をやってください。

    親機のパソコンは：

    1. 1準備するもの

      💡 インターネットが必要なのは、手順2で Node.js を入手する最初の1回だけです。院内にインターネットがない場合は、自宅などのパソコンでダウンロードして USB メモリで持ってきてください。

    2. 2親機に「Node.js（ノード ジェイエス）」を入れる 最初の1回だけ

      親機を動かすための無料の部品です。

      1. ブラウザで nodejs.org/ja を開く
      2. 「LTS」と書かれたほうのダウンロードボタンを押す（「最新版」ではなく LTS）
      3. ダウンロードしたファイル（node-v○○-x64.msi）をダブルクリック
      4. ダウンロードしたファイル（node-v○○.pkg）をダブルクリック
      5. 「Next」を押していく。設定は何も変えなくて大丈夫です。途中の「Tools for Native Modules」のチェックは入れなくてOK
      6. 「続ける」→「インストール」。Mac のパスワードを聞かれたら入力
      7. 「Finish」で完了
      8. 「インストールが完了しました」で「閉じる」

    3. 3電子カルテのフォルダを親機に置く

      1. emr フォルダを、親機のドキュメントなどわかりやすい場所にコピーする
      2. 置いたら、あとから場所を動かさないでください（カルテのデータは emr/server/data に保存されます）

    4. 4親機を起動する

      1. emr フォルダの中の「電子カルテを起動（Windows）.bat」をダブルクリック
      2. emr フォルダの中の「電子カルテを起動（Mac）.command」をダブルクリック
      3. 青い画面で「Windows によって PC が保護されました」と出たら → 「詳細情報」→「実行」
      4. 「開発元を確認できないため開けません」と出たら → 「完了」を押してから、システム設定 → プライバシーとセキュリティ を開き、下の方の「このまま開く」を押す（古い Mac では、ファイルを右クリック →「開く」→「開く」）
      5. 黒い画面が出て「起動しました」と表示されれば成功です。この画面は閉じないでください

      ⚠ ここが一番大事

      初回は「Windows セキュリティの重要な警告」という画面が出ます。

      ①「プライベート ネットワーク」にチェックを入れる　②「アクセスを許可する」を押す

      これを押さないと、子機からつながりません。うっかり閉じてしまったら、下の「つながらないとき」の④を見てください。

      ⚠ ここが一番大事

      「“node”がネットワーク上の受信接続を許可しますか？」と出たら「許可」を押してください。

      これを押さないと、子機からつながりません。

      起動すると、このページが親機のブラウザで自動で開き、一番上に「✅ 親機は動いています」と表示されます。

    5. 5初期設定をする（親機で1回だけ）

      1. 親機のブラウザで http://localhost:8080 を開く（このページの一番上の「電子カルテを開く」でもOK）
      2. 医療機関名と、管理者（医師）のログインID・パスワードを登録する
      3. すでに「1台だけで使う版」を使っていた場合は、初期設定画面の「そのデータを引き継ぐ」から、バックアップファイルで移行できます

      💡 管理者は2人以上作っておくのがおすすめです。管理者がパスワードを忘れても、もう1人が再発行できます。

    6. 6子機をつなぐ

      子機は、親機と同じ Wi-Fi につないでおいてください（「ゲスト」「Guest」と付いた Wi-Fi は不可）。

      パソコン

      1. Chrome・Edge・Safari などのブラウザを開く
      2. 上のアドレス欄に、親機に表示されているアドレス（例 http://192.168.1.23:8080）をそのまま入力して Enter
      3. ログイン画面が出たら、お気に入り（ブックマーク）に登録

      iPad・iPhone

      1. カメラアプリで、親機の画面の QRコードを写す
      2. 出てきた黄色い表示をタップ
      3. Safari で開いたら、共有ボタン（□に↑）→「ホーム画面に追加」

      Android

      1. カメラ（または Google レンズ）で QRコードを写す
      2. Chrome で開く
      3. 右上の︙ →「ホーム画面に追加」

      ✅ ログイン画面の下に「院内サーバーに接続しています」と出ていれば完了です。ログイン後は画面右上に緑色の「院内サーバー接続中」が表示されます。

    やっておくと安心な設定（おすすめ）

    親機がスリープしないようにする

    親機がスリープすると、子機からカルテが使えなくなります。

    • スタート → 設定 → システム → 電源（または「電源とバッテリー」）→「画面とスリープ」
    • 「電源接続時に、次の時間が経過した後にデバイスをスリープ状態にする」を「なし」にする（画面が消えるのは問題ありません）
    • アップルメニュー → システム設定 → ディスプレイ →「詳細設定…」（ノートの場合は「バッテリー」→「オプション…」）
    • 「ディスプレイがオフのときに自動でスリープさせない」（電源アダプタ使用時）をオンにする
    親機のアドレスが変わらないようにする

    ルーターの電源を入れ直したときなどに、親機のアドレスの数字が変わることがあります。変わると、子機のブックマークでつながらなくなります（親機の黒い画面に「アドレスが変わりました」と表示されます）。

    かんたんな方法：名前で開く
    子機で http://（親機の名前）.local:8080 を開くと、アドレスが変わってもつながります。iPad・iPhone・Mac・Windows ではたいてい使えます（Android では使えないことがあります）。

    確実な方法：ルーターで固定する
    ルーターの設定画面で「DHCP 固定割当」「IPアドレスの予約」などの項目を探し、親機を登録します。名前はルーターのメーカーによって違うので、説明書かメーカーのサイトで「固定IP」と調べてください。わからなければ、ルーターを設置した業者さんに「このパソコンのIPアドレスを固定してほしい」と頼めば通じます。

    パソコンの電源を入れたら自動で親機を起動する
    • キーボードの Windows キーと R を同時に押す → shell:startup と入力して Enter
    • 開いたフォルダに、「電子カルテを起動（Windows）.bat」を右クリックでドラッグして「ショートカットをここに作成」
    • アップルメニュー → システム設定 → 一般 → ログイン項目
    • 「＋」を押して「電子カルテを起動（Mac）.command」を選ぶ

    毎日の使い方

    ☀ 朝

    親機の電源を入れて、起動ファイルをダブルクリック（自動起動にしていれば不要）。子機はブックマークを開いてログイン。

    🌙 夜

    そのまま電源を入れておいても大丈夫です。終了するときは、黒い画面で Ctrl＋C。（×で閉じてもデータは消えません）

    💾 バックアップ

    親機が毎日自動で作ります（emr/server/data/backups、30日分）。週に1回は、管理画面の「バックアップを書き出す」で USB メモリなど親機とは別の場所にも保存してください。

    うまくいかないとき

    症状に近いものを開いてください。

    子機で「このサイトにアクセスできません」「接続がタイムアウトしました」と出る

    上から順に確認してください。たいてい①〜④のどれかです。

    1. 親機の黒い画面は開いていますか？ 閉じていたら、起動ファイルをもう一度ダブルクリック。
    2. 親機のパソコン自身では開けますか？ 親機のブラウザで http://localhost:8080 を開く。開けなければ親機の問題なので、黒い画面に出ているメッセージを確認。
    3. 子機は親機と同じ Wi-Fi ですか？ Wi-Fi の名前（SSID）を見比べてください。「ゲスト」「Guest」「-g」が付いた Wi-Fi は、ほかの端末と通信できないようになっています。スマホ・タブレットは、モバイル通信（4G/5G）ではなく Wi-Fi になっているか確認。
    4. Windows のファイアウォールで止められていませんか？
      • スタート → 設定 → ネットワークとインターネット → Wi-Fi（有線ならイーサネット）→ つながっているネットワーク名 →「ネットワーク プロファイルの種類」を「プライベート ネットワーク」にする
      • それでもだめなら：スタートで「ファイアウォール」と検索 →「Windows Defender ファイアウォール」→ 左の「Windows Defender ファイアウォールを介したアプリまたは機能を許可」→「設定の変更」→ 一覧の「Node.js JavaScript Runtime」の「プライベート」にチェック → OK
    5. Mac のファイアウォールで止められていませんか？ システム設定 → ネットワーク → ファイアウォール →「オプション」→ 一覧の「node」を「受信接続を許可」にする。
    6. セキュリティソフト（ウイルスバスター、ノートン、ESET など）を入れていませんか？ そのソフト独自のファイアウォールで止まっていることがあります。ソフトの設定で「Node.js」または「node」を許可してください。
    7. アドレスの数字が変わっていませんか？ 親機の黒い画面（またはこのページの一番上）に出ている最新のアドレスで開き直し、ブックマークを作り直してください。
    8. ルーターの「端末どうしの通信をさせない」設定がオンになっていませんか？ ルーターによって「プライバシーセパレーター」「AP アイソレーション」「ネットワーク分離」などの名前です。オフにしてください。
    起動ファイルを開いても黒い画面がすぐ消える／「node が見つかりません」と出る

    Node.js が入っていません。手順2をやってください。入れた直後なら、パソコンを再起動してからもう一度試してください。

    「すでに起動しているようです」と出る

    黒い画面がもう1つ開いています。画面の下のタスクバー（Mac は Dock）を確認して、開いている方を使ってください。

    「ポート 8080 は使用中のため、8081 を試します」と出た

    ほかのソフトが同じ番号を使っていたので、自動で別の番号にしました。子機で開くアドレスの最後も :8081 などに変わるので、黒い画面に出ているアドレスで開いてください。

    子機の画面に赤い「サーバー未接続・再接続中…」が出る

    親機と通信できていません。親機がスリープしていないか、電源が切れていないか、子機の Wi-Fi が切れていないかを確認してください。つながれば自動で再開します。入力中の内容は消えません。

    「時刻のずれが大きすぎます」と出る

    子機の時計がずれています。子機の設定で「日付と時刻」を「自動で設定」にしてください。

    「院内ネットワーク以外からの接続は受け付けません」と出る

    安全のため、院内の Wi-Fi からしかつながらないようになっています。子機がモバイル通信や VPN 経由になっていないか確認してください。

    パスワードを忘れた

    管理者に「管理 → 利用者 → パスワード再発行」をしてもらってください。
    管理者本人が忘れて、ほかに管理者がいない場合は、データを開く方法がありません（暗号化しているため、開発者でも開けません）。管理者は必ず2人以上作っておいてください。

    安全のために守ること

    • 院内の Wi-Fi には必ずパスワードをかける（WPA2 または WPA3）。患者さん用のフリー Wi-Fi は、ルーターの「ゲスト」機能で分ける。
    • ルーターで「ポート開放」をしない。親機は院内からの接続だけを受け付ける作りですが、外から入れる設定は絶対にしないでください。
    • 親機のパソコンにもログインパスワードをかけ、席を離れるときはロックする（Windows＋L）。
    • カルテの中身は子機の中で暗号化してから親機に送られます。院内の通信を盗み見られても、カルテの内容は読めません。親機のパソコンにも暗号化されたまま保存されます。

    この電子カルテは試作です。実際の診療で使う前に、厚生労働省「医療情報システムの安全管理に関するガイドライン」に沿った運用ができているか確認してください。
