# 📓 ノートブックAI（ローカル版 NotebookLM）

自分の資料（PDF・Word・議事メモ・Webページなど）を読み込ませて、
**資料にもとづく質問応答（出典つき）** と、**要約・議事録・計画書・報告書などの文書作成** ができるアプリです。
AIは自分のPCの中で動くので、**資料が外部に送られることはありません**。

> ゴルフ場アプリ本体とは無関係で、公開サイト（gh-pages）にも含まれません。

## できること
- **資料の取り込み**：PDF・Word(.docx)・PowerPoint(.pptx)・テキスト・Markdown・字幕(.vtt/.srt)・Webページ・貼り付けたテキスト。ドラッグ＆ドロップにも対応
- **チャット**：選んだ資料だけを根拠に回答。文中の `[1]` を押すと、根拠になった資料の箇所が見られる
- **文書作成（ワンクリック）**：要約／議事録／計画書／報告書／ブリーフィング／よくある質問／時系列／ToDo抽出
  - 「追加の指示」で「A4 1枚で」「会議名は〇〇」などの条件をつけたり、自由な文書を作らせたりできる
  - 長い資料は自動で分けて読み、要点を集めてからまとめる（モデルが一度に読める量を超えても大丈夫）
- **編集・保存・書き出し**：作った文書は画面で編集し、メモとして保存したり **Word(.docx)**・Markdown で書き出したりできる。
  作った文書を「資料に追加」すれば、次のチャットや文書作成の材料にもなる
- ノートブックを案件ごとに分けて管理できる。スマホ幅の画面にも対応

## はじめかた

### 1. Ollama（ローカルでAIを動かすソフト）を入れる
https://ollama.com からインストールし、ターミナル（Windowsは PowerShell）でモデルをダウンロードします。

```bash
ollama pull qwen3:8b     # 文章を書くモデル（日本語が得意。約5GB）
ollama pull bge-m3       # 検索用（多言語対応の埋め込みモデル。任意だが推奨）
```

PCの性能に合わせてモデルを選んでください：

| PCのメモリ（GPUのVRAM） | おすすめ | 備考 |
| --- | --- | --- |
| 8GB | `qwen3:4b` | 軽い。長い文書は少し苦手 |
| 16GB | `qwen3:8b` | 標準。議事録・要約なら十分 |
| 24GB 以上 | `gemma3:12b`・`qwen3:14b` | 計画書など長い文書の質が上がる |
| 32GB 以上 | `qwen3:30b-a3b` | 大きいわりに速い |

### 2. このアプリを起動する
Python 3.9 以上が必要です。

- **Windows**：`start.bat` をダブルクリック
- **Mac / Linux**：`./start.sh`

または手動で：
```bash
cd local-notebook
pip install -r requirements.txt   # PDF・Word を読む／書き出す部品（任意）
python server.py
```
ブラウザで http://localhost:8765 が開きます。

### 3. 最初の設定
右上の **⚙ 設定** で次のように設定して「保存」します。
- 文章を書くモデル：`qwen3:8b`
- 検索用の埋め込みモデル：`bge-m3`（空でもキーワード検索で動きます）

LM Studio や llama.cpp を使う場合は「OpenAI互換」を選び、URLを `http://localhost:1234/v1` などにします。

## 使い方のコツ
- **議事録**：会議の録音を文字起こししたテキスト（Teams・Zoom・Google Meet の文字起こし、.vtt ファイルなど）や手書きメモを貼り付けて「🗒️ 議事録」
- **計画書**：打ち合わせメモ・過去の企画書・参考資料を入れて「📋 計画書」。「追加の指示」に目的や予算の条件を書くと精度が上がる
- **資料の選択**：左のチェックを外した資料は、チャットにも文書作成にも使われない
- **長い資料**：設定の「文脈の長さ」を増やすと一度に読める量が増える（メモリを多く使う）。
  目安は 8GB で 8192、16GB で 16384、24GB 以上で 32768
- **出力の形を変えたい**：`prompts.py` の指示文を書き換えれば、社内の書式に合わせられる

## しくみ
```
資料 ─▶ 文字を取り出す(extract.py) ─▶ 700字ずつに分ける ─▶ 検索用に保存(store.py)
                                                         │
質問 ─▶ 関係する部分を探す(retrieve.py: キーワード検索 + 意味検索) ─▶ その部分だけ見せて回答(ai.py)
文書作成 ─▶ 資料全体を読む（長ければ分けて要点を抜き出し → まとめる） ─▶ 文書
```

| ファイル | 中身 |
| --- | --- |
| `server.py` | Webサーバー（Python標準ライブラリのみ） |
| `llm.py` | Ollama / OpenAI互換サーバーとの通信 |
| `extract.py` | PDF・Word・PowerPoint・HTMLから文字を取り出す |
| `retrieve.py` | 分割と検索（2文字ずつのキーワード検索 BM25 ＋ ベクトル検索 を RRF で合成） |
| `ai.py` | 出典つき回答・長文の分割要約（map-reduce） |
| `prompts.py` | AIへの指示文と文書テンプレート（ここを編集してカスタマイズ） |
| `export.py` | Markdown → Word 変換 |
| `static/` | 画面（HTML・CSS・JavaScript。外部ライブラリなし） |
| `data/` | ノートブック・資料・メモの保存先（Gitには含めない） |

## 注意
- 回答や文書はAIが作るので、間違いが含まれることがあります。数字・日付・固有名詞は必ず元の資料で確認してください（`[1]` から確認できます）
- 画像だけのPDF（スキャンしたもの）は文字を取り出せません
- `python server.py --host 0.0.0.0` にすると同じLAN内の他の端末からも使えますが、パスワード保護はないので信頼できるネットワークでだけ使ってください
