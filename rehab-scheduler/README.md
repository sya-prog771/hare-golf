# リハビリ予定 自動作成（オフライン版）

`index.html` をダブルクリックしてブラウザ（Chrome / Edge 推奨）で開くだけで動きます。インターネット接続・インストールは不要です。データはそのブラウザ内に自動保存されます（JSONバックアップ可）。

## できること
- 患者300名規模の1日〜31日分の予定を数秒で自動作成（PT/OT/ST、20分=1単位）
- 担当療法士優先、患者のNG時間（入浴・透析・検査）、希望時間帯、優先度、実施曜日
- 療法士の勤務時間・休日曜日・休暇日・会議時間・1日/週の上限単位
- **パターン**（平日標準／土曜短縮／日祝最小体制／人員不足（均等配分）／午前のみ…）を保存し、曜日・祝日ごとに自動で切り替え
- 急な欠勤はクリック1つで切替 →「この日だけ作り直す」
- 療法士別予定表（横軸＝スタッフ、縦軸＝時刻）上でドラッグ＆ドロップの手動修正（5分刻み。クリックで開始時刻・療法士・単位数も変更可）、🔒固定（作り直しても残る）
- 患者別予定も時間割表示（横軸＝患者、縦軸＝時刻）。病棟ごとに表示・印刷・CSV、一覧表示にも切替可
- 患者・療法士をCSV（Excel、UTF-8/Shift_JIS）で取り込み／書き出し、予定一覧CSV、印刷
